



# User Story: User Role (Basic Employee)

## Role Overview

**Role ID**: 3  
**Database Field**: `user` (session variable: `#session.User`)  
**Hierarchy Position**: Base level employee, all employees have this role  
**Primary Responsibility**: Create indents for material requirements, view own indents, search master data

### Permissions Matrix (From Database)
```
user_id: 3
role_name: User
role_view: FALSE (uses workflow-specific permissions)
role_add: FALSE (uses workflow-specific permissions)
role_edit: FALSE (uses workflow-specific permissions)
role_delete: FALSE (uses workflow-specific permissions)
role_status: 1

Workflow-Specific Permissions:
- indent_create: TRUE (can create new indents)
- indent_view_own: TRUE (can view own indents)
- indent_edit_draft: TRUE (can edit draft indents before submission)
- material_search: TRUE (can search material catalog)
- master_data_view: TRUE (can view master data read-only)
```

### Key Characteristics
- **Indent Creation**: Primary function is to create material indents for department needs
- **Own Data Access**: Can only view/edit their own indents (not others')
- **Read-Only Master Data**: Can search and view materials, departments, UOMs (no modifications)
- **No Approvals**: Cannot approve any indents or workflows
- **Department Scoped**: Can only create indents for their assigned department(s)
- **Status Tracking**: Can track status of submitted indents (pending, approved, rejected)

## Typical Daily Workflows

### Morning Routine (9:00 AM - 9:15 AM)
1. **Login** → Dashboard shows:
   - ❌ My draft indents count
   - ❌ My pending indents count
   - ❌ Notifications (indent approvals/rejections overnight)

2. **Check Notifications**:
   - ❌ Read indent approval notifications
   - ❌ Read indent rejection notifications (check reason)
   - ❌ Click notification → view indent details

### Creating an Indent (As Needed, 2-3 times per week)
1. **Need Identification**:
   - Identify materials needed for work
   - Check if materials are in catalog
   - Determine quantities needed

2. **Create Indent**:
   - ❌ Click "Create Indent" button
   - ❌ Search materials (autocomplete)
   - ❌ Add materials to indent (name, quantity, UOM, justification)
   - ❌ Add multiple materials if needed
   - ❌ Save as draft (if not ready to submit)
   - ❌ Submit for approval (if ready)

3. **After Submission**:
   - ❌ Wait for notification
   - ❌ Track status in "My Indents" page
   - ❌ View approval workflow (who approved, pending with whom)

### Editing Draft Indents (Occasional)
1. **Review Drafts**:
   - ❌ Go to "My Indents" page
   - ❌ Filter by status "Draft"
   - ❌ Open draft indent

2. **Make Changes**:
   - ❌ Add more materials
   - ❌ Update quantities
   - ❌ Modify justifications
   - ❌ Save changes or submit

### Handling Rejected Indents (Occasional)
1. **Review Rejection**:
   - ❌ Receive rejection notification
   - ❌ Open indent details
   - ❌ Read rejection reason from approver

2. **Revise and Resubmit**:
   - ❌ Cannot edit rejected indent (create new one based on it)
   - ❌ Create new indent with corrected information
   - ❌ Submit for approval again
