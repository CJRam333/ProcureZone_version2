# User Story: Material Handling Roles (GoodsIncharge & GRNIncharge)

This document covers the two critical material handling roles.

---

# 1. GRNIncharge Role

## Role Overview

**Role ID**: 10  
**Database Field**: `grn_incharge` (session variable: `#session.GRNIncharge`)  
**Hierarchy Position**: Material receipt authority, reports to Admin/PlantManager  
**Primary Responsibility**: **CRITICAL** - Create Goods Receipt Notes (GRN) from POs, verify material receipt, match PO-receipt-GRN, close PO receipt cycle

### Key Characteristics
- **Critical in procurement workflow**: Without GRN, POs cannot be closed
- Receives receipt notes from FloorIncharge
- Creates formal GRN matching PO
- Verifies quantities and quality (preliminary)
- Forwards to QualityManager if detailed inspection required
- Updates inventory after GRN approval

### User Stories Summary

#### 1.1 View Pending POs for GRN
- ❌ View POs sent to vendor (awaiting receipt)
- ❌ View POs with receipt notes (from FloorIncharge, awaiting GRN)
- ❌ Filter by vendor
- ❌ Filter by expected delivery date
- ❌ Identify overdue POs (delivery date passed, no receipt)

**API Endpoints**:
- ❌ `GET /api/v1/grn/pending-pos` - POs awaiting GRN
- ❌ `GET /api/v1/grn/pending-pos?vendorId={id}` - Filter by vendor
- ❌ `GET /api/v1/grn/overdue-pos` - Overdue POs

#### 1.2 Create GRN from PO
- ❌ Select PO for GRN creation
- ❌ View PO details (items, quantities ordered, prices)
- ❌ View receipt note from FloorIncharge (if exists)
- ❌ Enter actual quantities received (may differ from PO)
- ❌ Enter batch numbers (if applicable)
- ❌ Enter expiry dates (if applicable)
- ❌ Add GRN remarks (condition, discrepancies)
- ❌ Save GRN as draft
- ❌ Submit GRN (updates inventory, closes/partially closes PO)

**API Endpoints**:
- ❌ `POST /api/v1/grns/from-po/{poId}` - Create GRN from PO
- ❌ `POST /api/v1/grns/drafts` - Save GRN as draft
- ❌ `PUT /api/v1/grns/drafts/{id}` - Edit draft GRN
- ❌ `POST /api/v1/grns/drafts/{id}/submit` - Submit GRN
- ❌ `POST /api/v1/grns/{id}/items` - Add item to GRN
- ❌ `DELETE /api/v1/grns/{id}/items/{itemId}` - Remove item

#### 1.3 Partial Receipt Handling
- ❌ Create GRN for partial receipt (some items received, some pending)
- ❌ Mark PO as "Partially Received"
- ❌ Track pending items (ordered - received = pending)
- ❌ Create subsequent GRNs when remaining items arrive

**API Endpoints**:
- ❌ `GET /api/v1/purchase-orders/{id}/receipt-status` - Check PO receipt status
- ❌ `GET /api/v1/purchase-orders/{id}/pending-items` - Get pending items

#### 1.4 PO-GRN Mismatch Handling
- ❌ Identify quantity discrepancies (received != ordered)
- ❌ Flag quality issues (damage, defects)
- ❌ Create debit note for shortages/damage
- ❌ Forward to QualityManager if inspection required
- ❌ Notify Procurement about discrepancies
- ❌ Hold GRN approval pending resolution

**API Endpoints**:
- ❌ `POST /api/v1/grns/{id}/report-discrepancy` - Report PO-GRN mismatch
- ❌ `POST /api/v1/grns/{id}/forward-to-quality` - Send to QualityManager
- ❌ `POST /api/v1/grns/{id}/hold` - Hold GRN pending investigation

#### 1.5 View and Manage GRNs
- ❌ View all GRNs (all statuses)
- ❌ Filter by status (draft, submitted, quality-check, approved, rejected)
- ❌ Filter by PO
- ❌ Filter by vendor
- ❌ Filter by date range
- ❌ View GRN details (items, quantities, remarks)
- ❌ View GRN approval history (if required quality check)
- ❌ Print GRN

**API Endpoints**:
- ❌ `GET /api/v1/grns` - List all GRNs with pagination
- ❌ `GET /api/v1/grns?status={status}` - Filter by status
- ❌ `GET /api/v1/grns?poId={id}` - Filter by PO
- ❌ `GET /api/v1/grns/{id}` - Get GRN details
- ❌ `GET /api/v1/grns/{id}/pdf` - Download GRN PDF

#### 1.6 GRN Dashboard & Metrics
- ❌ View GRN dashboard (pending, completed today, this month)
- ❌ View GRN creation metrics (avg time to create GRN after receipt)
- ❌ View discrepancy rate (GRNs with mismatches)
- ❌ View pending quality checks

**API Endpoints**:
- ❌ `GET /api/v1/grn/dashboard` - GRN dashboard data
- ❌ `GET /api/v1/grn/metrics` - GRN metrics

**Total Endpoints for GRNIncharge**: ~22

**Legacy Features**:
- `/PlantIndentIsuueNote/indent_for_Grp.jsp` - GRN creation from PO
- `/PlantIndentIsuueNote/indent_for_Grp_list.jsp` - GRN list
- `/PlantIndentIsuueNote/goods_receipt_not_for_plant.jsp` - Non-plant GRN

**Current Status**: ❌ **0% Complete** - No GRN module exists (CRITICAL BLOCKER)

# 2. GoodsIncharge Role

## Role Overview

**Role ID**: 11  
**Database Field**: `goods_incharge` (session variable: `#session.GoodsIncharge`)  
**Hierarchy Position**: Stores/warehouse manager, manages material issues  
**Primary Responsibility**: Issue materials to departments, manage stores inventory, track material movements

### Key Characteristics
- Manages warehouse/stores inventory
- Issues materials based on approved indents
- Creates issue notes
- Tracks issued materials
- Monitors stock levels and reorders
- Coordinates with IssueConfirm role for issue validation

### User Stories Summary

#### 2.1 View Approved Indents for Issue
- ❌ View approved indents pending material issue
- ❌ View indents with GRN completed (materials available)
- ❌ Filter by department
- ❌ Filter by material
- ❌ Check inventory availability before issue

**API Endpoints**:
- ❌ `GET /api/v1/issues/approved-indents` - Indents pending material issue
- ❌ `GET /api/v1/issues/approved-indents?departmentId={id}` - Filter by department
- ❌ `GET /api/v1/inventory/check-availability?materialId={id}&quantity={qty}` - Check stock

#### 2.2 Create Material Issue Note
- ❌ Select approved indent for issue
- ❌ View indent details (materials, quantities requested)
- ❌ Check warehouse inventory for each material
- ❌ Create issue note (full or partial issue)
- ❌ Select storage location (bin, rack, shelf)
- ❌ Enter batch number (FIFO/LIFO)
- ❌ Add issue remarks
- ❌ Save issue note as draft
- ❌ Submit issue note (updates inventory, notifies requester)

**API Endpoints**:
- ❌ `POST /api/v1/issue-notes/from-indent/{indentId}` - Create issue note from indent
- ❌ `POST /api/v1/issue-notes/drafts` - Save draft
- ❌ `PUT /api/v1/issue-notes/drafts/{id}` - Edit draft
- ❌ `POST /api/v1/issue-notes/drafts/{id}/submit` - Submit issue note
- ❌ `GET /api/v1/inventory/batches?materialId={id}` - Get available batches (FIFO)

#### 2.3 Partial Issue Handling
- ❌ Issue partial quantities (if full quantity not available)
- ❌ Mark indent as "Partially Issued"
- ❌ Track pending issue quantities
- ❌ Create subsequent issue notes when stock replenished

**API Endpoints**:
- ❌ `GET /api/v1/indents/{id}/issue-status` - Check indent issue status
- ❌ `GET /api/v1/indents/{id}/pending-issue` - Get pending issue quantities

#### 2.4 View and Manage Issue Notes
- ❌ View all issue notes (all statuses)
- ❌ Filter by status (draft, submitted, confirmed, closed)
- ❌ Filter by department
- ❌ Filter by date range
- ❌ View issue note details
- ❌ Print issue note
- ❌ Track issue confirmation (by IssueConfirm role)

**API Endpoints**:
- ❌ `GET /api/v1/issue-notes` - List all issue notes
- ❌ `GET /api/v1/issue-notes?status={status}` - Filter by status
- ❌ `GET /api/v1/issue-notes/{id}` - Get issue note details
- ❌ `GET /api/v1/issue-notes/{id}/pdf` - Download issue note PDF

#### 2.5 Inventory Management
- ❌ View stores inventory (all materials)
- ❌ View material-wise stock levels
- ❌ View stock by location (bins, racks)
- ❌ Identify low-stock materials (below reorder level)
- ❌ View stock movement history
- ❌ Perform stock adjustments (with approval)

**API Endpoints**:
- ❌ `GET /api/v1/inventory` - View stores inventory
- ❌ `GET /api/v1/inventory/material/{id}` - Material stock details
- ❌ `GET /api/v1/inventory/low-stock` - Low stock materials
- ❌ `GET /api/v1/inventory/material/{id}/movements` - Stock movement history
- ❌ `POST /api/v1/inventory/adjustments` - Create stock adjustment

#### 2.6 Issue Dashboard & Reports
- ❌ View issue dashboard (pending, issued today, this month)
- ❌ View issue metrics (avg issue time, pending confirmations)
- ❌ Generate issue reports (by department, by material)
- ❌ View department-wise material consumption

**API Endpoints**:
- ❌ `GET /api/v1/issues/dashboard` - Issue dashboard data
- ❌ `GET /api/v1/issues/metrics` - Issue metrics
- ❌ `GET /api/v1/reports/material-issues` - Issue reports

**Total Endpoints for GoodsIncharge**: ~18

**Legacy Features**:
- Issue note creation forms
- Inventory management pages
- Stock movement tracking
- Batch/FIFO management

**Current Status**: ❌ **0% Complete** - No material issue or stores inventory module exists

## Combined Implementation Summary

### Total Endpoints: ~40
- **GRNIncharge**: 22 endpoints (CRITICAL for procurement cycle)
- **GoodsIncharge**: 18 endpoints (CRITICAL for material distribution)

### Critical Dependencies

**GRNIncharge Dependencies**:
1. PO module must exist (Procurement role)
2. Receipt note entity from FloorIncharge
3. Quality inspection module (QualityManager role)
4. Inventory entity for stock updates

**GoodsIncharge Dependencies**:
1. Indent module (User role)
2. Approval workflow (DeptHead role)
3. Inventory module
4. Issue confirmation module (IssueConfirm role)

### Workflow Integration

**GRN Workflow**:
```
Vendor delivers → FloorIncharge receives → GRNIncharge creates GRN → 
QualityManager inspects → GRN approved → Inventory updated
```

**Material Issue Workflow**:
```
User creates indent → DeptHead approves → GoodsIncharge issues → 
IssueConfirm validates → Issue confirmed → Inventory updated
```

### Implementation Priority

**P0 - CRITICAL**:
- GRN module (22 endpoints) - **Required to close PO cycle**
- GRN creation from PO (6 endpoints)
- GRN-PO matching and validation (4 endpoints)

**P1 - HIGH**:
- Material issue module (18 endpoints) - **Required for material distribution**
- Issue note creation from indent (5 endpoints)
- Inventory tracking (5 endpoints)

**P2 - MEDIUM**:
- Advanced GRN features (partial receipt, discrepancy handling) - 8 endpoints
- Advanced issue features (batch management, FIFO) - 6 endpoints
- Dashboards and reports - 6 endpoints

### Estimated Effort: 5 weeks
- Week 1: GRN entity + basic GRN creation (6 endpoints)
- Week 2: GRN workflow + PO matching (8 endpoints)
- Week 3: Inventory module + material issue foundation (8 endpoints)

## Database Entities Required

### GRN Module
```sql
-- GRN Header
CREATE TABLE grn_header (
    grn_id INT PRIMARY KEY AUTO_INCREMENT,
    grn_number VARCHAR(50) UNIQUE,
    po_id INT,  -- FK to purchase_order
    receipt_note_id INT,  -- FK to receipt_note (from FloorIncharge)
    grn_date DATE,
    status VARCHAR(50),  -- DRAFT, SUBMITTED, QUALITY_CHECK, APPROVED, REJECTED
    created_by INT,  -- FK to employee
    created_date TIMESTAMP,
    remarks TEXT,
    FOREIGN KEY (po_id) REFERENCES purchase_order(po_id),
    FOREIGN KEY (receipt_note_id) REFERENCES receipt_note(receipt_note_id),
    FOREIGN KEY (created_by) REFERENCES employee(emp_id)
);

-- GRN Details
CREATE TABLE grn_detail (
    grn_detail_id INT PRIMARY KEY AUTO_INCREMENT,
    grn_id INT,  -- FK to grn_header
    material_id INT,  -- FK to material
    quantity_ordered DECIMAL(15,2),
    quantity_received DECIMAL(15,2),
    uom_id INT,  -- FK to umo
    batch_number VARCHAR(50),
    expiry_date DATE,
    unit_price DECIMAL(15,2),
    remarks TEXT,
    FOREIGN KEY (grn_id) REFERENCES grn_header(grn_id),
    FOREIGN KEY (material_id) REFERENCES material(material_id),
    FOREIGN KEY (uom_id) REFERENCES umo(umo_id)
);
```

### Material Issue Module
```sql
-- Issue Note Header
CREATE TABLE issue_note_header (
    issue_note_id INT PRIMARY KEY AUTO_INCREMENT,
    issue_note_number VARCHAR(50) UNIQUE,
    indent_id INT,  -- FK to indent
    issue_date DATE,
    status VARCHAR(50),  -- DRAFT, SUBMITTED, CONFIRMED, CLOSED
    issued_by INT,  -- FK to employee (GoodsIncharge)
    created_date TIMESTAMP,
    remarks TEXT,
    FOREIGN KEY (indent_id) REFERENCES indent(indent_id),
    FOREIGN KEY (issued_by) REFERENCES employee(emp_id)
);

-- Issue Note Details
CREATE TABLE issue_note_detail (
    issue_note_detail_id INT PRIMARY KEY AUTO_INCREMENT,
    issue_note_id INT,  -- FK to issue_note_header
    material_id INT,  -- FK to material
    quantity_requested DECIMAL(15,2),
    quantity_issued DECIMAL(15,2),
    uom_id INT,  -- FK to umo
    batch_number VARCHAR(50),
    storage_location VARCHAR(100),
    remarks TEXT,
    FOREIGN KEY (issue_note_id) REFERENCES issue_note_header(issue_note_id),
    FOREIGN KEY (material_id) REFERENCES material(material_id),
    FOREIGN KEY (uom_id) REFERENCES umo(umo_id)
);

-- Inventory
CREATE TABLE inventory (
    inventory_id INT PRIMARY KEY AUTO_INCREMENT,
    material_id INT,  -- FK to material
    plant_id INT,  -- FK to plant
    storage_location VARCHAR(100),
    batch_number VARCHAR(50),
    quantity_available DECIMAL(15,2),
    uom_id INT,  -- FK to umo
    last_updated TIMESTAMP,
    FOREIGN KEY (material_id) REFERENCES material(material_id),
    FOREIGN KEY (plant_id) REFERENCES plant(plant_id),
    FOREIGN KEY (uom_id) REFERENCES umo(umo_id)
);
```
