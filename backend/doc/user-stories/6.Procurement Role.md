# User Story: Procurement Role

## Role Overview

**Role ID**: 6  
**Database Field**: `procurement` (session variable: `#session.Procurement`)  
**Hierarchy Position**: Specialized procurement function, reports to senior management/Admin  
**Primary Responsibility**: Create and manage Purchase Orders (POs) from approved indents, manage vendor relationships, track order fulfillment

### Permissions Matrix (From Database)
```
procurement_id: 6
role_name: Procurement
role_view: FALSE (uses workflow-specific permissions)
role_add: FALSE (uses workflow-specific permissions)
role_edit: FALSE (uses workflow-specific permissions)
role_delete: FALSE (uses workflow-specific permissions)
role_status: 1

Workflow-Specific Permissions:
- po_create: TRUE (can create purchase orders)
- po_edit: TRUE (can edit POs before approval)
- po_view_all: TRUE (can view all POs)
- vendor_manage: TRUE (can create/update vendors)
- approved_indents_view: TRUE (can view all approved indents)
- material_pricing: TRUE (can view/update material prices)
- supplier_quotations: TRUE (can manage quotations)
- material_search: TRUE (can search material catalog)
- master_data_view: TRUE (can view master data read-only)
```

### Key Characteristics
- **PO Management**: Primary owner of purchase order lifecycle
- **Vendor Relations**: Manages vendor master data and relationships
- **Pricing Authority**: Can view and update material pricing
- **Approved Indents Queue**: Works from approved indents (approved by DeptHead)
- **Quotation Management**: Manages supplier quotations and price comparisons
- **No Approval Authority**: Cannot approve POs (Admin approves high-value POs)
- **Cross-Department**: Can view approved indents from all departments

## Typical Daily Workflows

### Morning Routine (8:30 AM - 9:00 AM)
1. **Login** → Procurement Dashboard shows:
   - ❌ Approved indents pending PO count (high priority!)
   - ❌ Draft POs count
   - ❌ POs pending approval count
   - ❌ Overdue POs count (pending receipt)
   - ❌ This month PO value

2. **Check Approved Indents Queue**:
   - ❌ Open approved indents list
   - ❌ Sort by oldest first (fairness)
   - ❌ Identify urgent/high-priority indents
   - ❌ Plan PO creation order

3. **Check Overdue POs**:
   - ❌ View overdue POs (pending receipt, delivery date passed)
   - ❌ Note vendors to follow up with
   - ❌ Prepare to update delivery dates if needed

### PO Creation (9:00 AM - 12:00 PM)
**Target**: Create 5-10 POs per morning

1. **For Each Approved Indent**:
   - ❌ Open indent details
   - ❌ Review materials and quantities
   - ❌ Select vendors (lookup quotations or last purchase vendor)
   - ❌ Enter unit prices (lookup last purchase price or quotation)
   - ❌ Set delivery date (negotiate with vendor or standard lead time)
   - ❌ Add terms and conditions
   - ❌ Save as draft

2. **Review Draft POs**:
   - ❌ Review all draft POs created
   - ❌ Verify vendor selection
   - ❌ Verify pricing
   - ❌ Verify delivery dates
   - ❌ Submit POs (triggers approval workflow if high-value)

### Vendor Management (12:00 PM - 1:00 PM)
1. **Follow Up Overdue POs**:
   - ❌ Call or email vendors for overdue POs
   - ❌ Get delivery updates
   - ❌ Update expected delivery dates in system
   - ❌ Add follow-up notes

2. **Vendor Inquiries**:
   - ❌ Check if any new vendor registrations
   - ❌ Update vendor information if needed
   - ❌ Rate vendors based on recent deliveries

### Afternoon Tasks (2:00 PM - 5:00 PM)
1. **Quotation Management** (as needed):
   - ❌ Create quotation requests for high-value indents
   - ❌ Record quotations received from vendors
   - ❌ Compare quotations
   - ❌ Select winning vendor
   - ❌ Create PO from winning quotation

2. **Price Updates** (as needed):
   - ❌ Update material prices based on market rates
   - ❌ Update prices based on quotations received
   - ❌ Review price trends

3. **Handle PO Approvals** (if Admin approved high-value POs):
   - ❌ Check if Admin approved any POs
   - ❌ Send approved POs to vendors (email with PO PDF)
   - ❌ Update PO status to "Sent to Vendor"

4. **Track Receipts**:
   - ❌ Check if any POs have been received (GRN created)
   - ❌ Review GRN details
   - ❌ Close PO if fully received
   - ❌ Follow up if partial receipt

### Weekly Tasks (Friday afternoon)
1. **Generate Weekly Report**:
   - ❌ PO summary report (last 7 days)
   - ❌ Vendor performance report
   - ❌ Overdue POs report
   - ❌ Export and email to Admin/management

2. **Review Metrics**:
   - ❌ Check average PO creation time
   - ❌ Check overdue POs rate
   - ❌ Check this month's PO value vs budget

## Security Considerations

### What Procurement CAN Do:
- ✅ View approved indents from ALL departments (cross-department access)
- ✅ Create POs from approved indents
- ✅ Edit draft POs before submission
- ✅ Submit POs for approval (if high-value)
- ✅ Track PO fulfillment
- ✅ Create and manage vendors
- ✅ View and update material pricing
- ✅ Manage supplier quotations
- ✅ View vendor performance
- ✅ Generate procurement reports

### What Procurement CANNOT Do:
- ❌ Approve high-value POs (Admin approves)
- ❌ Edit submitted POs (already in workflow)
- ❌ Delete vendors with existing POs
- ❌ Approve indents (DeptHead's job)
- ❌ Create indents (unless also has User role)
- ❌ Modify master data other than pricing
- ❌ Access admin functions
- ❌ Delete submitted POs (only drafts)
