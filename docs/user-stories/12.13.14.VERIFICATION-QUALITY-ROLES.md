# User Stories: Verification & Quality Roles

**Roles Covered**: IssueConfirm (12), ReceiptConfirm (13), QualityManager (14)  
**System**: ProcureZone - Procurement & Indent Management  
**Last Updated**: October 13, 2025

---

## Overview

These three roles form the **final verification layer** in the ProcureZone system, ensuring material movements are accurate, documented, and meet quality standards before being finalized in the system.

### Role Hierarchy
```
Quality Manager (14) ─── Final Quality Approval
         ↑
         │
Receipt Confirm (13) ─── Confirms Material Receipts
Issue Confirm (12) ───── Confirms Material Issues
```

---

# Role 12: Issue Confirm

**Role ID**: 12  
**Role Code**: IssueConfirm  
**Session Variable**: `#session.IissueConfirm` (note: typo in legacy code)  
**Hierarchy Level**: Verification Layer

## Role Description

The **Issue Confirm** role is responsible for final verification and confirmation of material issue notes before they are posted to inventory. This role acts as a critical control point to ensure materials issued from stores match physical quantities and documentation.

## Permissions from Legacy System

| Permission | Access Level | Notes |
|------------|--------------|-------|
| View | FALSE (workflow-specific) | Can view assigned issue notes |
| Add | FALSE | Cannot create issue notes |
| Edit | FALSE | Cannot modify issue notes |
| Delete | FALSE | Cannot delete issue notes |
| Confirm Issue | ✅ YES | Primary responsibility |
| Reverse Issue | ✅ YES (if not posted) | Can reverse before posting |
| View Inventory | ✅ YES | Can check stock levels |

## User Stories

### 1. Material Issue Confirmation

#### 1.1 View Pending Issue Notes
**As an Issue Confirm user**, I can:
- View all material issue notes pending confirmation
- Filter by:
  * Date range
  * Department
  * Material type
  * Issuing store
  * Priority/urgency
- See issue note details (materials, quantities, requestor)
- View original indent/requirement reference
- Check issuer's name and timestamp

**Acceptance Criteria**:
- Only see issue notes from my assigned locations/plants
- Can sort by date, priority, or value
- Can search by issue note number or material code
- Pending list refreshes in real-time

**Legacy Features**:

# Role 14: Quality Manager

**Role ID**: 14  
**Role Code**: QualityManager  
**Session Variable**: `#session.QualityManager`  
**Hierarchy Level**: Quality Assurance (Final Approval)

## Role Description

The **Quality Manager** is the highest authority for quality-related decisions in the ProcureZone system. This role performs quality inspections, approves/rejects material receipts based on quality standards, maintains quality records, and ensures compliance with specifications.

## Permissions from Legacy System

| Permission | Access Level | Notes |
|------------|--------------|-------|
| View | NULL (all quality records) | Can view all materials and quality data |
| Add | NULL (quality inspections) | Can create inspection records |
| Edit | NULL (quality records) | Can update inspection results |
| Delete | NULL (quality inspections) | Can void inspections (with reason) |
| Quality Approval | ✅ YES | Primary responsibility |
| Quality Rejection | ✅ YES | Can reject materials |
| Vendor Rating | ✅ YES | Can rate vendor quality |
| Inspection Reports | ✅ YES | Can generate quality reports |

## User Stories

### 1. Quality Inspection Management

#### 1.1 View Pending Inspections
**As a Quality Manager**, I can:
- View all materials pending quality inspection
- Filter by:
  * Receipt date
  * Vendor
  * Material type
  * Priority (critical items first)
  * Plant/location
  * Inspection due date
- See GRN details and PO specifications
- View material specifications and quality parameters
- Check if inspection is urgent (blocking production)

**Acceptance Criteria**:
- Pending list shows all materials requiring inspection
- Can prioritize by urgency flag
- Can see days since receipt (aging)
- Real-time updates as new GRNs arrive
- Color-coded by urgency (red = overdue)

**Legacy Features**:
```jsp
// From: web/WEB-INF/jsp/quality/quality_inspection_list.jsp
- Dashboard with pending inspection count
- Filterable grid with aging indicators
- Quick view GRN and PO details
- Urgency flags from procurement
```

**Backend Endpoints Required**:
```
❌ GET /api/v1/quality-inspections/pending
   Query: page, size, dateFrom, dateTo, vendor, materialType, plant, priority
   
❌ GET /api/v1/quality-inspections/{id}/specifications
   Returns: Required quality parameters and acceptance criteria
```

#### 1.2 Conduct Quality Inspection
**As a Quality Manager**, I can:
- Open quality inspection form for a GRN/Receipt
- View material specifications and standards
- Enter inspection results for each parameter:
  * Physical inspection (dimensions, weight, color, etc.)
  * Chemical analysis (composition, purity, etc.)
  * Performance tests (strength, durability, etc.)
  * Documentation check (certificates, test reports)
- Attach photos of samples
- Upload lab test reports (PDF, Excel)
- Record inspection date, time, location
- Specify sampling method and sample size
- Add detailed remarks and observations

**Acceptance Criteria**:
- All required parameters must be filled
- Can mark parameters as Pass/Fail/Conditional
- Must upload test report for critical materials
- Photos mandatory for visual inspection items
- Cannot save incomplete inspection
- Auto-saves draft for continuation later

**Legacy Features**:
```java
// From: src/com/nsl/procurement/action/QualityInspectionAction.java
- Method: createInspection()

- Saves to tbl_quality_inspection
- Links to tbl_grn_header
- Stores inspection parameters in tbl_quality_inspection_detail
```

**Backend Endpoints Required**:
```
❌ POST /api/v1/quality-inspections/create
   Body: {
     grnId: number,
     receiptId: number,

     }],

   }
   
❌ POST /api/v1/quality-inspections/{id}/save-draft
❌ POST /api/v1/quality-inspections/{id}/upload-documents
```

#### 1.3 Approve Material Quality
**As a Quality Manager**, I can:
- Approve material if all inspection parameters pass
- Add approval remarks and certification
- Specify approved quantity (can be partial)
- Set expiry date for quality clearance (if applicable)
- Generate quality certificate (printable)
- Trigger receipt confirmation workflow
- Update vendor quality rating
- Release material for stock addition

- All required parameters must pass
- Approval remarks mandatory
- Quality certificate auto-generated with digital signature
- GRN status updated to 'QUALITY_APPROVED'

- Material released for inventory posting
- Vendor quality score updated

#### 1.4 Reject Material Quality
**As a Quality Manager**, I can:
- Reject material if inspection parameters fail
- Specify rejection reason per parameter
- Document non-conformance details
- Attach evidence (photos, test reports)
- Specify rejection action:
  * Return to vendor (full rejection)
  * Conditional acceptance (reduced price)
  * Rework/retest (give vendor chance to fix)
  * Scrap/dispose
- Initiate vendor quality issue process
- Block material from stock addition
- Generate non-conformance report (NCR)

**Acceptance Criteria**:
- Rejection reason mandatory with evidence
- Must specify action required (return/rework/scrap)
- NCR generated automatically
- GRN status updated to 'QUALITY_REJECTED'
- Email notifications sent to:
  * Procurement (to coordinate with vendor)
  * GRN Incharge
  * Accounts (to hold payment)
  * Vendor (NCR and rejection details)
- Material blocked from inventory
- Vendor quality score negatively impacted

**Legacy Features**:

```java
- Triggers vendor return process
- Holds payment in accounting system
```

## Typical Daily Workflows

### Morning Routine (Quality Manager)
1. Review quality dashboard - check pending inspections
2. Prioritize urgent inspections (critical materials, production blockers)
3. Check overnight GRN arrivals requiring inspection
4. Review open NCRs and vendor responses
5. Follow up on overdue inspections

### Inspection Process
1. Select pending GRN from list
2. Review material specifications and PO requirements
3. Conduct physical/chemical/performance tests
4. Document results with photos and test reports
5. Approve or reject based on criteria
6. Generate quality certificate (if approved) or NCR (if rejected)
7. Notify stakeholders

### Vendor Quality Management
1. Review vendor quality ratings weekly
2. Track NCR resolution progress
3. Conduct vendor quality review meetings
4. Update vendor quality scores
5. Recommend vendor approval/suspension to procurement

### Reporting & Compliance
1. Generate daily inspection summary
2. Prepare weekly quality metrics for management
3. Conduct monthly quality management review
4. Maintain compliance documentation
5. Prepare for regulatory audits

## Integration Points

### With GRN Incharge
- Receives GRNs for quality inspection
- Provides quality clearance or rejection
- Coordinates on sampling and documentation

### With Receipt Confirm
- Quality approval unblocks receipt confirmation
- Quality rejection blocks inventory addition
- Shares quality certificates and NCRs

### With Procurement
- Provides vendor quality ratings for vendor selection
- Coordinates on quality rejections and returns
- Shares NCRs for vendor management

### With Inventory
- Quality approval releases material to stock
- Quality rejection prevents stock addition
- Shares quality certificates for material traceability

### With Accounts
- Quality rejection triggers payment hold
- Quality approval allows payment processing
- Shares NCRs for vendor payment disputes
