# User Story: Admin Role

## Role Overview

**Role ID**: 2  
**Database Field**: `admin` (session variable: `#session.Admin`)  
**Hierarchy Position**: Second-highest authority, reports to Super Admin  
**Primary Responsibility**: Manage master data, oversee users, generate reports, perform advanced operations

### Permissions Matrix (From Database)
```
admin_id: 2
role_name: Admin
role_view: TRUE
role_add: TRUE
role_edit: TRUE
role_delete: TRUE
role_status: 1
```

### Key Characteristics
- **Full master data CRUD access** (company, department, material, location, plant, section, UOM, crop)
- **User oversight** (view all users, reset passwords, but cannot create/modify Super Admins)
- **Advanced reporting** (all analytics, audit logs, system health)
- **Approval override** (can approve indents, POs in emergency situations)
- **System monitoring** (view logs, monitor workflows, check system status)
- **No system configuration** (cannot modify system settings, roles, or workflows - that's Super Admin only)

## Typical Daily Workflows

### Morning Routine (8:00 AM - 9:00 AM)
1. **Login** → Dashboard shows:
   - ❌ Pending approvals count (requires approval module)
   - ❌ New user registrations (requires user management)
   - ❌ System health status (requires monitoring module)
   - ❌ Yesterday's activity summary (requires reporting module)

2. **Check Pending Items**:
   - ❌ Review pending indent approvals that need override
   - ❌ Check new employee activations
   - ❌ Review system errors from overnight batch jobs

3. **Master Data Verification**:
   - ✅ Check new companies/departments added yesterday
   - ✅ Verify material master updates
   - ❌ Review audit logs for anomalies

### On-Demand Tasks
1. **User Support**:
   - ❌ Reset forgotten passwords (5-10 times daily)
   - ❌ Unlock accounts (2-3 times daily)
   - ❌ Activate new employee accounts (1-2 times daily)

2. **Master Data Operations**:
   - ✅ Create new department (2-3 times weekly)
   - ✅ Add new materials to catalog (5-10 times weekly)
   - ✅ Update company information (1-2 times monthly)

3. **Emergency Approvals**:
   - ❌ Override indent approval when DeptHead unavailable (1-2 times weekly)
   - ❌ Approve urgent PO when Procurement offline (rare, 1-2 times monthly)

4. **Reporting**:
   - ❌ Generate ad-hoc reports for management (2-3 times weekly)
   - ❌ Export master data for external systems (1-2 times weekly)
   - ❌ Investigate audit log queries from compliance team (1-2 times monthly)

### Periodic Tasks
1. **Weekly Tasks**:
   - ❌ Review weekly activity report
   - ❌ Check inactive user accounts
   - ❌ Verify role assignments
   - ❌ Generate master data quality report

2. **Monthly Tasks**:
   - ❌ Generate monthly audit report for compliance
   - ❌ Review and clean up inactive master data
   - ❌ Export monthly statistics for management
   - ❌ Verify system backups completed successfully

## Security Considerations

### What Admin CAN Do:
- ✅ Full CRUD on all master data
- ✅ View all employees and their roles
- ✅ Reset any user password (except Super Admin)
- ✅ Activate/deactivate user accounts (except Super Admin)
- ✅ View all audit logs
- ✅ Generate all reports
- ✅ Override approvals in emergencies (with justification)
- ✅ Monitor system health

### What Admin CANNOT Do:
- ❌ Create Super Admin accounts
- ❌ Modify Super Admin roles or permissions
- ❌ Delete Super Admin accounts
- ❌ Modify system configuration (roles, workflows, LDAP, etc.)
- ❌ Modify role permissions matrix
- ❌ Create new roles
- ❌ Access Super Admin-only logs
- ❌ Permanently delete data (soft delete only)

### Authorization Rules:
```java
// Current (Problematic - MANAGER doesn't exist in legacy)
@PreAuthorize("hasAnyRole('ADMIN', 'MANAGER')")

// Should Be (Map to actual legacy roles)
@PreAuthorize("hasAnyRole('ADMIN')")  // For Admin-only operations
@PreAuthorize("hasAnyRole('ADMIN', 'DEPT_HEAD', 'PROCUREMENT')")  // For operations that multiple roles can perform
```
